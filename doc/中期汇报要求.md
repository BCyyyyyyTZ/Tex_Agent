1. 项目简介  
   - 所选项目是什么  
   - 为什么需要做这个项目（背景、动机、价值）

项目名称：TeX_Agent —— 基于多智能体架构的论文写作增强系统

  背景：在学术科研领域，使用 LaTeX 进行高质量论文写作是一项较为繁琐的工作。研究人员需要在写作过程中同时兼顾海量文献的检索与梳理、严谨的逻辑框架构建、繁杂的格式排版等工作。目前市面上的通用大语言模型虽然具备一定的文本生成能力，但往往缺乏对 LaTeX 复杂代码结构的深层理解，且难以在长篇幅的学术写作中保持逻辑的连贯性和格式的稳定性，研究人员依然需要耗费大量精力在排版纠错和对内容的调整上。

  动机：为了解决上述痛点，我们希望打造一个专门针对 LaTeX 学术写作场景的智能辅助工具，它不应只是一个简单的对话智能体，而应该是一个能够模拟人类科研团队分工作业的协作系统。通过构建一个基于多智能体（Multi-Agent）架构的系统，我们将不同能力倾向的 Agent有机结合，并引入 RAG 和类似于 Git 的多分支上下文记忆机制。我们希望借此系统，精准切入学术写作中从文献调研、大纲构思、思路整理到格式调优的各个环节，实现更好的科研协同。

  价值：“TeX_Agent” 的核心价值在于极大地降低了高质量学术论文的写作阻力，并在严谨的科研辅助与个性化的交互中找到了平衡。它不仅能通过严格的 Checking-list 对照检查和自动化排版保障论文的规范性，还能在构思阶段提供启发式的大纲和段落思路，帮助用户克服“面对空白屏幕”的写作瓶颈。对于广大科研工作者和学生而言，TeX_Agent 是一个集检索、构思、写作、纠错、审查于一体的辅助工具，能够提升科研产出效率与论文最终质量。

2. 项目需求 
   - 项目整体需求  
   - 当前重点需求说明

**项目整体需求：**
本项目旨在构建一个全流程、多节点的 LaTeX 论文写作增强系统，核心需求主要涵盖以下五个维度：

+ 构思与结构规划：能够根据用户提供的主题或要求，生成论文大纲及结构优化建议；支持针对特定章节或段落的Outline，为用户梳理写作思路并整理出详细的段落大纲。

+ 文献与相关工作处理：接入外部学术 API，实现精准文献抓取与相关研究工作的查询和总结；并建立 RAG 库，提升系统的信息检索与生成质量。

+ 辅助写作与排版调优：在用户认可的思路和大纲基础上，进行高质量的论文内容辅助写作；深度解析 LaTeX 源码，识别语法错误、润色学术表达，并提供上下文连贯的结构性规范建议。

+ 质量控制与审查：引入 Checking-list 对照检查机制，系统能够根据用户提供的检查清单对论文进行自动化审查，并精准标明不符合要求的内容。

+ 系统底层架构支持：搭建基于动态路由（Router）与 Planner-Executor 机制的多智能体（MAS）框架；建立类似于 Git Branch 的多分支上下文管理，支持用户在不同写作思路间的无缝切换与回退。

**重点需求说明：**

截至项目中期针，我们的研发精力主要聚焦于搭建系统的核心骨架与实现审查功能，重点需求如下：

+ 基础 MAS 框架搭建：完成几种基础 Agent 架构的独立开发与调试，并初步搭建多agent框架，实现 Agent 之间的基础消息传递与协同工作。

+ 质量控制与审查：引入 Checking-list 对照检查机制，系统能够根据用户提供的检查清单对论文进行自动化审查，并精准标明不符合要求的内容。

+ 最小可行性写作链路（MVP）： 实现基于命令行的基础交互，用户可以自定义工作流，也可以由plan-agent自适应地设计工作流；智能体能够基于 Checking-list 的回复审查结果，还可以根据用户的论文主题，实现简单的论文内容。

**已完成的功能：**

+ 全链路MVP：实现可运行的智能体（通过`python main.py`），支持task（按指定工作流执行任务）、plan（通过plan-agent动态规划任务）的不同模式进行交互
