# Overleaf Module and Compilation Fixes

## Added: ui/overleaf/

Independent Overleaf-style LaTeX editor, no changes to ui/web/server or latex/ghost_cli.

### Files
- ui/overleaf/server.py - FastAPI backend (16 API + 2 page routes)
- ui/overleaf/thesis_generator.py - Agent-based thesis generation
- ui/overleaf/static/ - Frontend (index.html, editor.html, editor.css, editor.js)
- overleaf.py / overleaf.bat - Quick start scripts

### Features
- Landing page: upload zip / generate from outline+template
- Editor: file tree + code editor, PDF preview with draggable divider
- Selection polish: select text, auto polish
- Full document polish
- Auto-save with status indicator
- Ctrl+S save, Ctrl+Enter compile

## Compilation Fixes

latexmk requires Perl (missing); pdflatex had MiKTeX font issues.

### Fixes
1. Removed -halt-on-error (conflicted with nonstopmode)
2. Rebuilt pdflatex format: initexmf --dump=pdflatex
3. Rebuilt font maps: initexmf --mkmaps
4. Fallback: latexmk fails -> pdflatex
5. Fixed hardcoded main.tex in fallback
6. Fixed fallback placement (was after return, dead code)
7. Success = PDF exists, not just return code

### API Changes
- PolishBody/GenerateBody at module level (fix 422)
- Compile supports ?file= query param
- PDF endpoint serves from project root
