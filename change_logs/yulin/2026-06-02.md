# yulin 2026/6/2

## Web UI：顶会投稿日历（独立功能）

### 功能说明

- **数据**：`config/conferences/deadlines_2026.json`（约 30 场，CV / NLP / ML / 网络 / 系统 / 安全 / 机器人等；自 2026-06 起未来一年参考截止日）
- **API**：`GET /api/conferences/deadlines?fields=cv,nlp`（静态 JSON，非实时抓取）
- **逻辑**：`ui/web/conferences_data.py`
- **未接入** `tools/tool_list` 与 Plan 工作流
- **倒计时**：按 AoE 截止时间实时显示 `天 / 时 / 分 / 秒`
- **链接校验**：修复 SIGCOMM、EMNLP、COLING、The WebConf、INFOCOM、ATC、IROS 等未来年份/异常官网链接，改用可访问的官方系列页或组织页
- **顶栏简化**：`工作流` 下拉框仅在 `task` 模式显示，`auto` / `plan` 模式隐藏
- **用户设置**：新增本地设置弹窗，支持主题色与用户资料偏好；数据保存在浏览器 `localStorage`，暂不引入数据库
- **设置页优化**：升级为科技感设置入口与控制面板，新增界面图案选择；修复设置按钮点击兜底并提升静态资源版本到 `settings-2`
- **主题覆盖**：扩大主题色覆盖范围到全局背景、顶栏、侧栏、聊天气泡、输入区和列表，减少大块纯黑区域
- **主题补充**：新增 `纯黑` / `纯白` 非渐变主题；将界面图案改为前景低透明覆盖层，使网格/电路/轨道图案切换更明显
- **主题细化**：纯黑/纯白禁用渐变与图案覆层，并覆盖侧栏内部面板、输入、列表、聊天气泡等区域；主题按钮预览改为真实底色
- **白色主题修正**：补全工作流列标题、说明、节点表单、预览画布和 SVG 节点的浅色覆盖，避免白色主题下残留深色块
- **布局拖动**：扩大列间拖动命中区并改用 PointerEvent，修复右侧资料栏边界较难拖动的问题
- **图案调优**：降低图案密度，网格/电路/轨道纹理改为更稀疏的背景
- **图案再调优**：进一步降低背景 pattern 透明度与密度，尤其拉大轨道星图轨道间距，避免界面过密

### 入口位置（两个，避免顶栏拥挤）

1. **左上角标题旁**：`◈ 顶会日历` 青色按钮，紧挨「TeX Agent」标题
2. **右下角悬浮按钮**（FAB）：`◈ 顶会日历`

**VS Code / Cursor 侧栏（代理模式）** 只有精简聊天 UI，不含完整顶栏。侧栏顶部有 **「打开顶会投稿日历」** 按钮，或命令面板执行 **「TeX Agent: 打开顶会投稿日历」**；完整 UI 请 **Ctrl+Alt+T** 打开 Simple Browser。

### 看不到按钮时

- 已提交到 git 的旧版 `index.html` **不含日历**；本地改动需 **重启 server** 并 **Ctrl+F5** 强刷
- `server.py` 已对 `/` 返回 `Cache-Control: no-store`，减少浏览器强缓存旧页
- `ui/web/ide_launch.py` 与 VS Code/Cursor 扩展打开 Simple Browser 时会自动追加 `_t=时间戳`，避免复用旧标签页的旧 DOM
- 直接访问 `http://127.0.0.1:8765/?open=calendar` 可自动弹出日历浮层

### 前端文件

- `ui/web/static/conferences_calendar.css`

### 使用

1. 重启 `python -m ui.web.server`
2. 浏览器 **强制刷新**（Ctrl+F5），避免旧版 `index.html` 缓存
3. 点击上述任一入口 → 浮层内按领域筛选 → 查看倒计时与官网链接

### 维护

每年更新 `config/conferences/deadlines_2026.json`；日期为常见轮次参考，**请以各会议官网为准**。
