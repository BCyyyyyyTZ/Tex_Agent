# yulin 2026/6/5（工具箱专项）

## 概述

本轮工作对 Web UI「工具箱」弹窗进行一轮专项优化，重点改进标题生成的 LLM prompt 风格差异化，并修复工具箱若干细节问题。

---

## 一、标题生成（paper_title_tool）

### 1.1 混合模式（3 本地 + 2 OpenAI）

- 固定 3 条本地模板标题（即时生成，无需 API）+ 可选 2 条 OpenAI 兼容 API 生成标题。
- 默认勾选「启用 OpenAI 生成 2 条」；未配置 `OPENAI_API_KEY` 时自动退化为纯本地，并在结果行提示原因。
- API 复用项目现有 `LlmClient`，读取 `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `LLM_MODEL`，不引入任何 Gemini 依赖。

### 1.2 风格差异化 prompt

| 风格 | prompt 策略 |
|------|-------------|
| **正经学术风** | 要求可投稿、信息密度高、命名方法/数据集/贡献、禁止幽默与叹号、结构多样化（冒号副标题、via/through 等）；提供 NeurIPS/ACL/CVPR 级别示例 |
| **趣味脑洞风** | 要求幽默或含梗、PhD 生活感、不能出现正经学术套话（"A Comprehensive Survey" 等被明确禁止）；必须包含关键词，避免与正经风格同质化 |

### 1.3 本地模板去重修复

- 旧版 while 循环在模板池较小时会产生重复标题。
- 新版：追踪已用标题 `seen_lower` 集合，最多 40 次尝试内保证不重复。

### 1.4 前端体验改进

- 提交按钮旁显示当前模式：「正在生成（3 本地 + 2 AI）…」或「正在生成（本地模板）…」。
- 生成完成后状态栏明确反馈 `hybrid` / `template-only` / `template-partial` 三种模式。
- API 跳过原因（如未配置 key）在状态栏直接展示，不再藏在结果文本里。

## 二、工具箱 UI 细节优化

### 2.1 结果阅读体验

- 代码/文本预览区字体从 12px 提升到 12.5px，行高 1.7，支持 `pre-wrap` 换行。
- 标题生成结果区单独放大至 13.5px / 行高 1.9，便于直接阅读英文标题。
- 工具箱面板宽度从 860px 扩至 900px，最大高度从 820px 扩至 860px，减少小屏内容裁切。

### 2.2 措辞优化

- 概念图「调试模式，跳过 Gemini」→「手动输入 Mermaid 代码（跳过 Gemini，直接渲染）」，语义更准确。
- 标题生成 hint 文案补充说明本地/API 各自的触发条件和 fallback 行为。

### 2.3 静态资源版本

- `drawing_tools.css?v=4`
- `drawing_tools.js?v=4`
