本轮主要是把「概念示意图 / 统计图表」从工作流里**抽离成独立绘图工具**，接入 Web UI 顶栏的「工具」入口，同时补了顶会日历入口与 RAG 图标的细节，方便你在不改 workflow 的前提下快速出图与查看会议时间。

## 一、独立绘图工具：统计图表 + 概念示意图

### 1.1 新增工具实现（后端）

- **`ChartPlotTool`**（`tools/chart_plot_tool.py`）
  - 支持 `bar` / `line` / `pie` 三类图表。
  - 入参为结构化 `data` 字段：
    - bar/line：`{"x": [...], "y": [...]}` 或 `{"x": [...], "series": [{"name": "...", "y": [...]}, ...]}`。
    - pie：`{"labels": [...], "values": [...]}`。
  - 依赖 `matplotlib`（Agg 后端），输出 PNG 文件路径，元数据里带上 `chart_type` 和标题。
- **`ConceptDiagramTool`**（`tools/concept_diagram_tool.py`）
  - 负责把概念描述或直接提供的 Mermaid 代码渲染为概念示意图（PNG）。
  - 支持两种用法：
    - 有 Gemini Key：传入 `prompt`/`title`，用 `GeminiClient` 生成 Mermaid，自动去掉 ```mermaid 包装，仅接受单段 `flowchart`/`graph` 代码。
    - 无 Gemini Key：直接在 `mermaid_code` 字段里粘贴 Mermaid，跳过 LLM，仅做渲染。
  - 渲染使用 `mermaid.ink`：构造 `pako:` 压缩 + Base64 URL，支持多次重试。
  - 提供共用工具函数：
    - `web_tool_output_dir()`：统一输出到 `outputs/web_tool_outputs/`。
    - `unique_output_path(prefix, ext=".png")`：生成带短随机后缀的文件名（便于 Web UI 使用）。

### 1.2 Web API 封装

- 在 `ui/web/server.py` 新增数据模型与接口：
  - `ChartPlotBody`、`ConceptDiagramBody`、`DrawingToolResponse`（Pydantic）。
  - `POST /api/drawing/chart-plot`
    - 调 `ChartPlotTool`，输出路径统一通过 `unique_output_path("chart")` 生成。
    - 返回前端相对 URL：`/api/drawing/output/{filename}`。
  - `POST /api/drawing/concept-diagram`
    - 调 `ConceptDiagramTool`，既支持 `prompt`+LLM，也支持纯 `mermaid_code`。
    - 失败时在 `error` 里带上提示，成功时额外返回 `mermaid_code` 便于前端展示。
  - `GET /api/drawing/output/{filename}`
    - 仅允许访问 `outputs/web_tool_outputs/` 下的 PNG；做了文件名净化与存在性校验。

## 二、Web UI：顶栏「工具」入口 + 绘图弹窗

### 2.1 顶栏入口与布局

- 在 `ui/web/static/index.html` 的顶栏 panel 区增加一个与 **RAG / 工作流 / 分支 / 资料** 并列的 **第 5 个按钮「工具」**：
  - 使用图标按钮样式，默认只显示图标，悬停时浮出文字提示（与 Cursor 顶栏交互类似）。
  - 为避免误触侧栏折叠逻辑，在 `panel_toggles.js` 里对 `data-drawing-tools-open` 做了特别判断，不再参与 `TexAgentPanels` 的显隐切换。
- 在主 DOM 末尾追加绘图工具弹窗：
  - `#drawing-tools-overlay`：半透明暗色遮罩层，支持 `Esc` 关闭与点击空白关闭。
  - `#drawing-tools-panel`：居中面板，延续设置弹窗的科技感样式。
  - 顶部 head 区包含标题「绘图工具」和说明「独立于工作流 · 统计图表与概念示意图」。

### 2.2 绘图工具弹窗交互（前端 JS + CSS）

- **前端脚本：**`ui/web/static/drawing_tools.js`
  - 统一的 `apiBase()`，复用现有 `/api/` 前缀逻辑。
  - 支持 Tab 切换：
    - `统计图表`（chart）：默认选中。
    - `概念示意图`（diagram）。
  - **统计图表 Tab：**
    - 表单字段：图表类型（bar/line/pie）、标题、X/Y 轴标签、数据 JSON 文本框。
    - 提交时：
      - 将 JSON 文本解析为对象（带错误提示），然后 POST 到 `/api/drawing/chart-plot`。
      - 成功后展示结果区：内嵌 `<img>` + 「下载 PNG」按钮，自动加时间戳防缓存。
    - 辅助逻辑：
      - 切换为 `pie` 类型时自动填充 `{"labels": [...], "values": [...]}` 示例；
      - 切回 `bar`/`line` 时恢复 `{"x": [...], "y": [...]}` 示例。
  - **概念示意图 Tab：**
    - 字段包括：概念描述（可空）、图标题、Mermaid 代码。
    - 提交时：
      - 始终 POST 到 `/api/drawing/concept-diagram`，服务端负责决定是否调用 Gemini。
      - 成功后展示 PNG；若后端返回 `mermaid_code`，在下方 `<pre>` 中同步显示用作调试。
      - 若未配置 Gemini Key，通常建议只在 `mermaid_code` 中直接粘贴 Mermaid。
  - 新增「清空重置」按钮：
    - 图表 Tab：重置表单，恢复默认示例 JSON，清空状态文案与结果图片。
    - 概念图 Tab：重置所有输入，并填入一段简单的默认 Mermaid 示例，隐藏结果和代码预览。
  - 错误处理：
    - 请求异常 / 服务端 `success=false` 时，在对应 status 文本处展示红色错误信息（`is-error` 类）。
- **前端样式：**`ui/web/static/drawing_tools.css`
  - 定义绘图工具弹窗的遮罩、面板、Tab、表单网格、按钮行、状态提示、结果预览与代码预览样式。
  - 适配暗色主题，整体风格与用户设置面板保持一致。
  - 在小屏幕下收窄表单为单列布局。

## Web：独立绘图工具面板（与工作流解耦）

### 功能说明

- **目标**：把「统计图表」「概念示意图」从工作流节点中抽离出来，作为 Web UI 顶栏独立工具入口，方便临时画图、不绑定当前对话/工作流。
- **工具实现**：
  - `tools/chart_plot_tool.py`：使用 `matplotlib` 根据用户给定数据生成柱状图（bar）、折线图（line）、饼图（pie），输出 PNG 路径。
  - `tools/concept_diagram_tool.py`：
    - 默认：调用 `GeminiClient` 生成 Mermaid flowchart 代码，再通过 `mermaid.ink` 渲染为 PNG。
    - 调试/无 Key：支持直接在 `mermaid_code` 字段粘贴 Mermaid 代码，**跳过 Gemini** 直接渲染。
  - 新增 `web_tool_output_dir()` 与 `unique_output_path()`，所有 Web 工具输出集中到 `outputs/web_tool_outputs/` 目录，文件名带前缀与短 UUID，便于区分与清理。
- **后端 API**（FastAPI）：
  - `POST /api/drawing/chart-plot`：接受 chart 配置 JSON，调用 `ChartPlotTool`，返回 `output_url` 与本地 `output_path`。
  - `POST /api/drawing/concept-diagram`：接受 `prompt` / `title` / `mermaid_code`，调用 `ConceptDiagramTool`，返回渲染结果与最终 `mermaid_code`（便于复制）。
  - `GET /api/drawing/output/{filename}`：从 `outputs/web_tool_outputs/` 读取 PNG，提供浏览器预览与下载。
- **前端入口与交互**：
  - 顶栏原有 RAG/工作流/分支/资料四个按钮右侧，新增第 5 个 **「工具」** 图标按钮（✎），点击后弹出绘图工具浮层，**不影响** 左侧工作流与聊天。
  - 浮层采用与用户设置面板类似的暗色科幻风样式（半透明遮罩 + 居中卡片），通过 `body.drawing-tools-open` 锁定滚动。
  - 面板内分两个 Tab：
    - 「统计图表」：编辑 chart 类型与数据 JSON，一键生成图表。
    - 「概念示意图」：填写概念描述与标题，或直接粘贴 Mermaid 代码生成结构图。

### 表单与使用体验

- **统计图表**：
  - 支持两种数据格式：
    - 单系列：`{"x": [...], "y": [...]}`
    - 多系列：`{"x": [...], "series": [{"name": "S1", "y": [...]}, ...]}`
  - 饼图数据：`{"labels": [...], "values": [...]}`
  - 提交后在右下方显示状态（成功/错误），下方区域展示生成的 PNG 预览，并提供「下载 PNG」按钮。
  - 新增「清空重置」按钮：一键恢复默认示例数据、清除状态与预览，方便多次试图。
- **概念示意图**：
  - 支持两种模式：
    - 有 Gemini Key：填写「概念描述」（prompt）和可选「图标题」，自动生成 Mermaid flowchart 并渲染。
    - 无 Gemini Key：直接在「Mermaid 代码」文本框中粘贴/编辑代码，点击生成时走纯渲染路径。
  - 生成后展示：
    - PNG 预览（支持下载）。
    - 下方显示最终 Mermaid 代码文本，便于复制到论文或其它工具。
  - 同样提供「清空重置」按钮：重置表单内容、恢复内置示例 Mermaid 与状态。

### 安全与健壮性

- 后端对 Mermaid 输出做校验：必须以 `flowchart`/`graph` 开头，否则返回错误与原始代码（用于排查 prompt）。
- 生成图片统一走 `mermaid.ink` 带重试逻辑（指数回退），确保网络偶发错误不会直接崩溃。
- 绘图接口使用 `anyio.to_thread.run_sync` 将阻塞绘图与 HTTP 请求放到线程池，避免占用主事件循环。
