## 2026-05-07 更新内容

### 把RAG相关功能加入Web-ui

在 Web UI 中新增并完善了 RAG 管理能力，支持在同一页面内完成资料入库、记录查询与记录删除，降低了在命令行与页面之间来回切换的成本。

#### 增加（录入）

- 实现思路：在 Web UI 中提供独立的 RAG 录入区，将“文件选择 + 元信息填写 + 入库提交”整合到同一流程，确保用户可在可视化界面完成资料注入。  
- 使用方式：在 `RAG管理` 的“录入”区域选择文件，可选填写 `Source` 和 `metadata JSON`，点击“上传并入库”即可完成新增。  
- 交互优化：已支持查看当前已选文件，并可通过减号按钮取消误选文件后重新选择。

#### 查询

- 实现思路：将“语义查询”和“按 metadata 查询”统一为一个查询入口，通过“查询方式”切换不同查询路径，结果统一展示在同一个结果框中。  
- 使用方式：在“查询”区域先选择查询方式；  
  - 语义查询：输入查询文本并设置 Top-K；  
  - Metadata 查询：输入字段名/字段值进行筛选。  
- 展示方式：查询结果集中展示在结果列表中，列表内部支持滚动查看更多内容，并展示关键信息（如记录 id、source、metadata 摘要等）。

#### 删除

- 实现思路：在 Web UI 中补齐删除能力，支持“按 id 定向删除”和“按 source 批量删除同源记录”两种常见场景。  
- 使用方式：在“删除”区域可选择：  
  - 按记录 ID 删除：输入完整 id 后执行；  
  - 按 source 删除：输入 source 值后执行批量删除。  
- 配合建议：可先通过查询确认目标记录，再执行删除，删除后再次查询用于校验结果是否符合预期。

### 实际支持Web-ui中上传Skill和Checklist

类比上传文件的写法，补齐Skills和Checklists的选择文件上传功能

### 支持选择的文件撤销

在选择文件后，可以点击文件名旁边的“减号”，取消选择此文件
