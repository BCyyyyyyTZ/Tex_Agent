#### 实现一个初步的pdf解析工具

**具体信息见[说明文档](../../doc/RAG说明文档.md)的“外部调用说明部分”**，这里简单说一下调用方法：

首先要更新一下依赖库和环境变量（**注意：目前多于30页的pdf文件不支持解析，因为会有cpu内存不够的问题**）

```bash
pip install -r requirements.txt
cp .env.example .env

# 可选内容进行调用或测试
python rag/docling_parse.py <源文件路径> [-o 输出根目录]
```

#### 添加单元测试

##### DoclingParseTool 单元测试

> 目录：tests/test_tools/test_docling_parse_tool.py

```bash
# 执行全部测试，包括现场对一个pdf进行解析，非常耗时
pytest tests/test_tools/test_docling_parse_tool.py -v

# 跳过真实解析的快测试
pytest tests/test_tools/test_docling_parse_tool.py -v -m "not integration"

# 只做现场解析pdf的慢测试，但解析结果不会保存
pytest tests/test_tools/test_docling_parse_tool.py -v -m integration
```
