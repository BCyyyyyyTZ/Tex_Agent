#### 实现手动注入文件到向量数据库的方法

方法：**Tex_Agent/rag/rag_index_cli.py**

需要在Tex_Agent根目录执行：

```bash
python rag/rag_index_cli.py              # 交互输入路径
# 或者
python rag/rag_index_cli.py a.md b.tex   # 直接指定文件
```
