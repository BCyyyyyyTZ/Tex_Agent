## 2026-05-22 更新内容

> 对照文档：[TeX_Agent LaTeX 子系统分阶段实现路线图](../../doc/TeX_Agent%20LaTeX%20子系统分阶段实现路线图.md)（阶段 0～6 已标 **已完成**；阶段 7+ 未做）。

本轮在仓库内自底向上补齐 **LaTeX 诊断子系统 MVP**：统一数据契约 → 纯函数/服务 → Tool → LangGraph 工作流（无 LLM）。路径规则全程走 `latex/paths.py`（POSIX 相对路径、Windows/Linux 一致）。

### 一、阶段 0：契约与包骨架

**实现**

- `latex/models.py`：`DiagnosticIssue`、`Suggestion`、`ProjectIndex`、`LabelDef`、`RefEntry`、`BibEntry`、`ProjectConventions` 等（Pydantic v2）
- `latex/constants.py`：`Severity`、`IssueSource`、metadata 键（`__latex_project__`、`__latex_diagnostics__` 等）
- `latex/serialize.py`：`to_json` / `from_dict` 供 Tool 与测试复用
- `issue.id` 规则：`{source}:{rel_path}:{line}:{column}`

**验证**

```bash
pytest tests/test_latex/test_models.py -v
```

### 七、阶段 6：诊断工作流 `latex_diagnose_v0`（无 LLM）

**功能与效果**

纯 Tool 链（无 Agent、不耗 API）：

```text
latex_project → chktex → latexmk → latex_merge → latex_slice(error) → latex_report
```

- `config/workflow/workflow_latex_diagnose_v0.json`
- `config/workflow_registry.json` 注册名：`latex_diagnose_v0`
- `tools/latex_merge_tool.py`：合并 chktex / latexmk / parser（未定义 ref）issues，写入 `__latex_diagnostics__`
- `tools/latex_report_tool.py`：终态 report JSON（`diagnostics`、`slices`、`project` 摘要）
- `workflow/nodes.py`：Tool 返回的 `__latex_project__` / `__latex_diagnostics__` 提升到 `state.metadata` 顶层
- `latex/coerce_payload.py`、`latex/diagnose_io.py`：兼容 `tool.run(**dict)` 与工作流 `${metadata.*}` 模板

**用户输入（CLI / Web task）**

JSON 字符串，至少：

```json
{"root": "tests/fixtures/latex/multifile", "main_tex": "main.tex"}
```

`main_tex` 建议显式传入（latexmk 需要；否则尝试从扫描推断）。

**验证**

```bash
# 单元测试（不依赖 TeX / openai）
pytest tests/test_workflow/test_latex_diagnose_v0.py -v -m "not slow"

# 命令行端到端（需完整 Python 依赖；有 TeX 时 issues 更丰富）
python main.py task --wf latex_diagnose_v0 "{\"root\":\"tests/fixtures/latex/multifile\",\"main_tex\":\"main.tex\"}"
```

PowerShell 下注意 JSON 转义；路径可用 `/` 或 `\`。

**预期结果（终节点 `latex_report`）**

- `state.output` 为 report JSON，含：
  - `project`：`main_tex`、`file_count` 等摘要
  - `diagnostics.issues`：合并后的 `DiagnosticIssue` 列表
  - `slices`：仅 **error** 级 issue 的源码片段（`snippet` + 行号区间）
- 顶层 `metadata["__latex_project__"]`、`metadata["__latex_diagnostics__"]` 已填充
- 无 TeX 时：chktex/latexmk 可能 `issues=[]`，warnings 含 `chktex_not_found` / `latexmk_not_found`，流水线仍可跑通
- 有 TeX 且使用 `broken_braces` 等夹具时：更易出现 `latexmk` 来源的 error 与非空 `slices`

端到端 mock 测试（需安装 `openai` 等主仓依赖，否则 skip）：

```bash
pytest tests/test_workflow/test_latex_diagnose_v0.py::test_latex_diagnose_v0_invoke_mocked -v
```
